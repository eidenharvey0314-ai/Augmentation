Deploy Free to GitHub Pages

  1. Create a new repository on GitHub named vr-camera-app.
  2. Upload this file as index.html directly into the main repository branch (main).
  3. Go to Settings → Pages in your GitHub repository.
  4. Under Build and deployment → Source, select Deploy from a branch.
  5. Set Branch to main / /(root) and click Save.
  6. Your mobile VR app will be live globally at https://yourusername.github.io/vr-camera-app/.

* Note: Webcams require HTTPS, which GitHub Pages provides automatically for free!
